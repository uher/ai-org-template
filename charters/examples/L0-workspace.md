# L0 — 워크스페이스 컨트롤타워 (예시)

**성격:** 메타 조율 — 트리 구조·채널·규칙 자체를 다룬다. 가장 추상적인 레벨.
**한 줄 목표:** 채널이 몇 개로 늘어나도 전체가 일관되게 굴러가도록 구조·규칙·라우팅을
관리한다.
**자식 노드:** L1

## 이 노드가 다루는 것

- 트리 구조 변경 (레벨 추가/이동, 노드 신설·폐지)
- 락 규칙, 세션 네이밍 규칙, 세션-노드 라우팅(어떤 첫 마디가 어떤 charter로 붙는지)
- 워크스페이스 공통 문서(`GUIDE.md`, 루트 규칙 파일) 관리
- 크로스프로젝트 조율 — 한 프로젝트의 결정이 다른 프로젝트에 영향을 줄 때

## 이 노드가 다루지 "않는" 것

- 특정 제품의 일상 운영·우선순위 → **L4** (그 프로젝트의 PM)
- 기능 구현·버그 수정 → **L5.x**
- 사업/시장 전략 → L1·L2·L3

## 원칙 (이 트리의 DNA — 하위 레벨이 물려받는 것)

이 워크스페이스에서 형성된 원칙은 L1 → L2 → L3 → L4 → L5로 흘러 내려가, 하위 레벨이
자기 스코프 안에서 내리는 판단에 반영되는 것을 의도한다. 하위가 다르게 판단할 수도 있지만
그건 **예외이자 의식적 선택**이어야 하고, 왜 벗어났는지를 그 레벨 charter에 남긴다.

- 되돌릴 수 있게 만든다 (백업·기록이 먼저, 실행이 나중).
- 실패는 지우지 않고 릴리스 노트에 남긴다 — 같은 실수를 두 번 하지 않기 위해.
- 세션이 아니라 파일이 진실이다.
