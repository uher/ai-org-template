# L5.1 backend — 릴리스 노트 (release notes)

> 이 노드에 가해진 변경의 버전 히스토리. 최신이 위.
> 형식·이유는 GUIDE.md 「버전화 원칙」 참조.
> 추가: `python3 control/node.py note L5.1 <버전> --changed "..."`

## 0.4.0 — 2026-07-25

- **바뀐 것 (changed):** 스키마 변경 절차를 '확장 → 백필 → 축소' 3단계로 고정
- **왜 (why):** 한 번에 바꾸면 배포 중간 상태에서 구버전 코드가 깨진다
- **이전 문제 (previous problem):** 2026-06-28 컬럼 rename 배포 중 구버전 파드가 5분간 500 응답
- **교훈·재사용 포인트 (lesson):** 스키마와 코드는 항상 두 버전이 공존하는 구간이 있다 — 그 구간에서도 양쪽이 다 동작해야 한다

## 0.3.0 — 2026-07-25

- **바뀐 것 (changed):** 쓰기 API에 Idempotency-Key 헤더를 필수화하고 멱등성 처리를 미들웨어 한 곳으로 모음
- **왜 (why):** 재시도 때 리소스가 중복 생성되는 사고를 구조적으로 막으려고
- **이전 문제 (previous problem):** 핸들러마다 개별 구현하다 두 엔드포인트에서 누락 → 중복 주문 3건 발생(2026-06-11)
- **교훈·재사용 포인트 (lesson):** '모든 핸들러가 지켜야 하는 규칙'은 규약이 아니라 통과 지점 한 곳(미들웨어)으로 강제한다
